## Best-Practice Hardening

| Area | Implementation |
|------|---------------|
| Permissions | `permissions: contents: read` (least privilege) |
| Concurrency | `group: ci-${{ github.ref }}, cancel-in-progress: true` |

| Timeout | 20 min (~4x pytest wall-time) |
| Exit-code integrity | `shell: bash` + `set -o pipefail` (BLOCKER fix) |
| Step summary | Pass/fail tally + last 40 lines → `$GITHUB_STEP_SUMMARY` |
| Artifacts | `junit-results.xml` + `pytest-output.log` (14-day retention) |
